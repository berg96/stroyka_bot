# Помощник плиточника — @Sanya_stroyka_bot

Телеграм-бот для мастера-отделочника: раскладка плитки, расход материалов, смета
заказчику.

## Зачем

Мастер считает на калькуляторе и записывает промежуточные цифры на бумажку, а
потом всё это суммирует. Онлайн-калькуляторов «площадь ÷ площадь плитки» много, но
они не отвечают на главные вопросы: **где встанет подрезка**, **не выйдет ли по краю
тонкая полоска** и **сколько это стоит для заказчика**.

## Что умеет

**🧱 Плитка.** Стена или пол → схема раскладки картинкой: целые плитки, подрезка
(выделена, с размерами), плитки под дверью не считаются. Считает плитку, клей (с
подбором гребёнки), затирку (по формуле через размер плитки и шов), СВП/крестики,
грунтовку, гидроизоляцию. Подсказывает, когда лучше класть от центра, а когда
повернуть плитку.

**📐 Площадь.** Прямоугольник, треугольник, четырёхугольник (по сторонам **и
диагонали** — по одним сторонам он не определяется), произвольный многоугольник
(стороны + диагонали из одного угла), Г-образная комната с коробом (конструктор из
прямоугольников). Кривой замер ловится: «из таких сторон треугольник не собирается».

**📋 Объекты.** Стены копятся в объекте, закупка сводится в один список.

**💰 Смета.** Прайс мастера → смета работ и материалов, PDF со схемами раскладки.

Размеры понимает как есть: `2.7 2.5` или `2700 2500`, `60х30` или `600 300`.

## Запуск

```bash
uv sync
cp .env.example .env   # вписать BOT_TOKEN
uv run python -m tilebot.main
```

Прод: `systemctl {start,stop,status} stroyka-bot`, логи — `journalctl -u stroyka-bot -f`.

## Устройство

```
src/tilebot/
  core/        расчёты без Telegram — тестируются отдельно
    geometry.py    площадь по замерам рулеткой
    layout.py      раскладка: сетка, подрезка, советы
    materials.py   расход клея, затирки, СВП
    estimate.py    смета по прайсу
  render/      схема раскладки (PNG) и смета (PDF)
  bot/         aiogram: хендлеры, клавиатуры, разбор ввода
  storage.py   SQLite: объекты, поверхности, прайс
```

Ядро не знает про Telegram — поэтому расчёты покрыты тестами: `uv run pytest`.

## Нормы расхода

Средние по производителям (Ceresit, Litokol, Vetonit); затирка — по формуле
`((A+B)/(A·B)) · толщина · шов · 1.6`. Фактический расход зависит от основания и
партии смеси, о чём бот честно пишет в смете.
