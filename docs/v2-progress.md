## 🔴 Фидбек Артёма вживую (v2 на plitka.mooo.com) — сделать в продолжении
1. **Шов — степпер мёртвый** (нет «−», «+» пустой). Причина: у API НЕТ правки
   `joint_mm` (задаётся только при создании). Починить ПРАВИЛЬНО = добавить правку шва:
   - `storage.py`: метод `set_tile_joint(project_id, tg_id, joint_mm)` по образцу
     `set_tile_size` — пройтись по всем SurfaceRow, `data["tile"]["joint_mm"] = joint_mm`.
     (Шов общий на объект, как и раскладка.)
   - `web/app.py`: в `PatchIn` поле `joint_mm: float | None` (ge=0, le=20); в
     `patch_project` — `if body.joint_mm is not None: await store.set_tile_joint(...)`.
     ⚠️ бот тоже считает шов — проверь, что бот не сломается (он joint не патчит,
     только читает; безопасно).
   - `app.js`: joint-степпер шлёт `livePatch({joint_mm})`, шаги напр. 1 / 1.5 / 2 / 3
     или ±0.5, дефолт из `r.tile.joint_mm`.
   - **Рестарт `stroyka-web`** после (иначе старый бэкенд молча проглотит joint_mm —
     pydantic extra ignore — и шов не изменится). Бэкенд-правки НЕ живые до рестарта,
     это безопасно; фронт живой — верни осторожно.
2. **Ввод значений с клавиатуры, не только ±.** Значение в `stepperRow` (`.cur`)
   должно тапаться и открывать поле ввода (или отдельный лист «введи число»). Касается
   шва, запаса, размера плитки. Идея: `.cur` → `contenteditable`/`<input>` с
   `inputmode=decimal`, на blur/Enter → livePatch с валидацией по min/max.
3. **Схему нельзя посмотреть крупно и скачать.** Схема — герой, но тап по ней ничего
   не делает. Сделать: тап по `.scheme` → полноэкранный вьюер (тёмный backdrop, картинка
   object-contain, pinch-zoom или хотя бы крупно, закрытие по тапу/свайпу). Плюс кнопка
   «Скачать»/«Сохранить». Скачивание в webview Telegram: сперва пробовать
   `tg.downloadFile({url, file_name})` (WebApp API ≥8.0), фолбэк — `<a download>` с
   blob-URL схемы (она уже тянется blob'ом в `loadScheme`). Имя файла — по объекту+стене
   (напр. «Ванная-Стена1.png»). Возможно, отдавать и всю смету-PDF на «Поделиться».

### 🔮 Крупная идея на будущее (Артём): КАРТА ПОЛА
И раскладка ламината, и углы плинтуса по-хорошему строятся из полигона комнаты:
ламинат — схемой как плитка (но по полу), углы плинтуса — из вершин полигона (выпуклая =
внешний угол, вогнутая = внутренний), а не руками. Большой отдельный движок (как раскладка
плитки, но для пола + геометрия углов). Фундамент есть — «📐 Площадь» (сложные формы через
диагональ/Герона), но там пока только площадь, не полигон-карта. Сейчас — предположение из
стен (ок для прямоугольной комнаты). Полноценная карта пола — следующий крупный шаг.
